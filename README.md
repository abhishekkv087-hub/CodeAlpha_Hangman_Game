# CodeAlpha Python Internship — Task 1: Hangman Game

## Project overview
A simple text-based Hangman game. The computer chooses one word randomly from a list of five words. The player guesses one letter at a time and can make up to six incorrect guesses.

## Python concepts used
- `random.choice()` to select a random word
- `while` loop to keep the game running
- `if-else` conditions to check guesses
- strings and lists to store the word and guessed letters
- input validation to handle invalid or repeated guesses

## Requirements
Python 3.8 or newer. No external libraries are needed.

## How to run
1. Download or clone this project.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python main.py
   ```

   If your computer uses the `py` command on Windows, you can run:

   ```bash
   py main.py
   ```

## How to play
- Type one alphabet letter and press Enter.
- Correct letters appear in their positions.
- You lose one attempt for each incorrect letter.
- Guess the full word before you use all six incorrect guesses.
